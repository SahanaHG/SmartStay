# LinkedIn Project Post

**SmartStay – Hotel Reservation & Room Management System (Java 21 + Executive PMS Dashboard)**

I am excited to share that I have completed **Task 4: Hotel Reservation System** as part of my **Java Programming Internship at CodeAlpha**! 🚀

For this project, I built **SmartStay**—a comprehensive hotel reservation architecture featuring pure Java 21 Object-Oriented design, persistent File I/O, and an executive desktop PMS dashboard.

### 🌟 Key Features:
- 🛎️ **Executive Welcome Intro & Staff Authentication**: Cinematic welcome screen transitioning to a secure front desk staff login portal.
- 📊 **Executive PMS Dashboard**: Real-time room availability status, live occupancy tracking, revenue KPI cards, and operational shortcuts.
- 🎯 **Smart Room Search & Compatibility Algorithm**: Ranks rooms with 0–100% compatibility scores based on dates, capacity, and budget.
- 🏨 **Multi-Tier Room Categories**: Standard, Deluxe, and Presidential Suite with dedicated pricing, capacity, and amenities.
- 💎 **Dynamic Pricing Engine**: Automatic weekend surcharges (+10%), long-stay discounts (-10% for 5+ nights), and returning guest loyalty tiers (Silver 5%, Gold 10%).
- 💳 **Simulated Payment Gateway**: Card, UPI, and Cash payments with transaction IDs and decline simulations.
- 🛡️ **Date-Range Overlap Logic**: Checks precise date intervals to eliminate double-booking while preserving multi-date availability.
- 📁 **Permanent File I/O Persistence**: Saves bookings, customers, rooms, and payments across application restarts.
- 🖥️ **Dual Interface Support**: Interactive GUI with dark glassmorphism styling + standalone CLI console mode (`--console`).

### 💻 Technologies & Concepts Applied:
- **Core Java (JDK 21)**: Abstraction, Inheritance, Polymorphism, Interfaces, Encapsulation
- **GUI & UI/UX**: Java Swing, custom dark theme, card layouts, table models
- **Data Structures**: Collections framework, `java.time` API
- **Storage**: Robust File I/O (`BufferedReader`, `BufferedWriter`)
