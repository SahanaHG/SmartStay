# LinkedIn Project Description

**SmartStay – Intelligent Hotel Reservation & Room Management System (Java)**

I built SmartStay as part of my CodeAlpha Java Programming Internship: a console-based hotel booking system in pure Java 21 with no frameworks.

What it does:
- Smart room search by type, guests, budget and dates, ranked with a match score
- Standard, Deluxe and Suite rooms with different pricing, capacity and amenities
- Booking, cancellation and refunds with auto-generated booking IDs
- Date-range availability that prevents double booking
- Smart pricing: weekend surcharge, long-stay and loyalty discounts, optional services
- Simulated payments (UPI, Card, Cash) with transaction IDs and decline handling
- Live hotel statistics and an admin panel for room management
- Permanent storage with File I/O, so bookings survive restarts

What I practised: abstraction, inheritance, polymorphism, interfaces, encapsulation, Java Collections, java.time, File I/O, input validation and clean separation of UI, logic and storage.
